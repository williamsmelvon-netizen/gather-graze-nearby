# Gather Graze Nearby

Create a mobile-first React + TypeScript + Tailwind + shadcn/ui app called Let’s Eat with a warm, friendly look (earthy green and warm cream palette, 16px minimum body text, large tap targets). Add routes for Home, Nearby, Cuisine, Recipe detail, Shopping list, About, and a hidden /admin route. Connect Supabase and create the tables in Section 4 of the attached product spec with the RLS rules described.
